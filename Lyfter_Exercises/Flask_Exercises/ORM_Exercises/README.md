## Commands to get started
1. Create an isolated environment inside the project (only once)
```
python3 -m venv .venv
```
2. Activate the created isolated environment (every time you open a new terminal)
```
source .venv/bin/activate
```
3. Install everything
```
python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt
```

## Project structure

```
├── app/                     # RUNTIME: everything the API imports
│   ├── __init__.py          # create_app()
│   ├── config.py
│   ├── database.py          # engine, session factory, Base
│   ├── hooks.py             # request_id, common headers
│   ├── errors/
│   │   ├── __init__.py
│   │   ├── exceptions.py    # domain errors (no Flask)
│   │   └── handlers.py      # exceptions → HTTP responses (Flask)
│   ├── routes/
│   ├── schemas/
│   ├── services/
│   ├── repositories/
│   └── models/
├── db/                   # TOOLING: run from the terminal, never imported by app/
│   ├── __init__.py
│   ├── migrations/       # generated by `alembic init db/migrations`
│   └── seeds/
│       └── __init__.py
├── tests/
│   └── conftest.py
├── alembic.ini            # generated by Alembic, at the root
├── .env / .env.example / .flaskenv / .gitignore
├── README.md
└── requirements.txt / requirements-dev.txt
```
